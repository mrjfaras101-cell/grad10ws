# 🐍 منصة أوراق عمل البايثون التفاعلية | مدرسة صويلح الثانوية للبنين

**إعداد المعلم:** أ. باسم النعيمي  
**الصف المستهدف:** الأول الثانوي الأكاديمي  
**العملة المعتمدة في التطبيقات:** الدينار الأردني (JOD)

---

## 📌 نبذة عن المشروع
مشروع تعليمي تفاعلي ومطبوع يضم **3 أوراق عمل تطبيقية (على شكل مشاريع مصغرة Mini-Projects)** في لغة البرمجة **بايثون (Python)** لطلبة **الصف الأول الثانوي الأكاديمي** في **مدرسة صويلح الثانوية للبنين**.

تغطي أوراق العمل المفاهيم الأساسية التالية بأسلوب التعلّم الذاتي المدعوم بالتلميحات (Hints):
1. **جمل الطباعة (`print`) وجمل الإدخال (`input`)** وتحويل الأنواع (`int`, `float`).
2. **المعاملات الحسابية** (`+`, `-`, `*`, `/`, `%`, `**`) وأولويات العمليات الحسابية.
3. **معاملات المقارنة** (`>=`, `<=`, `>`, `<`, `==`, `!=`).
4. **المعاملات المنطقية** (`and`, `or`, `not`).
5. **الجمل الشرطية** (`if`, `elif`, `else`) والشروط المتداخلة.

## 📂 محتويات المستودع (Repository Structure)

```text
├── index.html          # الصفحة الرئيسية للمنصة التفاعلية (تعمل مباشرة على GitHub Pages)
```

## 🚀 طريقة رفع المشروع ونشره كموقع ويب على GitHub Pages

1. قم بإنشاء مستودع جديد (New Repository) على حسابك في **GitHub** (مثلاً باسم `python-worksheets-sweileh`).
2. ارفع ملفات المشروع (`index.html`, `style.css`, `script.js`, `README.md`, ومجلد `word-files/`) إلى المستودع.
3. من داخل المستودع، انتقل إلى تبويب **Settings** (الإعدادات) ثم اختر **Pages** من القائمة الجانبية.
4. تحت قسم **Build and deployment** (المصدر Source)، اختر **Deploy from a branch**، ثم حدد الفرع **`main`** والمجلد **`/ (root)`** واضغط **Save**.
5. خلال ثوانٍ سيصبح موقعك متاحاً عبر رابط مباشر يمكنك مشاركته مع طلاب الصف الأول الثانوي الأكاديمي!
